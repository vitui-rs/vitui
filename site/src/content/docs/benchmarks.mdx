**A comparison against ratatui, Textual and notcurses, written to find out where this library
loses.** Every scene is a described picture at 120×40 — a terminal size, an initial screen and a
sequence of changes — and an arm may reach it any way its framework prefers. Nothing in a scene
definition says *widget*, *diff* or *layer*, because the comparison spans immediate-mode and
retained-mode designs and those words would have decided it in advance.

The suite **reports and does not block**. Four external projects' versions cannot gate this
repository's pull requests, so the report is committed and regenerated, and a number that gets worse
arrives as a diff a reviewer reads.

## Where the numbers come from

- **The scenes** are normative and written down before any arm was built.
- **Each arm** is a separate crate or project in `compare/arms/`, written against the rendering
  layer directly, because that is the only level at which four libraries of three designs are
  comparable at all. It is not the level at which anybody writes an application.
- **The harness** drives each arm through a pseudo-terminal and counts the bytes it writes, which is
  the one measurement that is the same question for every arm.

The full report, the findings that read it, and the scene definitions are in
[`compare/`](https://github.com/vitui-rs/vitui/tree/master/compare).
